# 위키 시작하기

**CS Hub 사내 개발팀 위키**에 오신 것을 환영합니다!

이 위키는 개발팀 내의 지식을 공유하고, 아키텍처 및 보안 정책을 관리하기 위해 구축되었습니다.

## 📖 수록 기술 문서
좌측 사이드바를 통해 다음 정책 문서들을 확인하실 수 있습니다:
- **API URL 정책**: API 엔드포인트 구성 및 포워딩 규칙
- **로그 및 모니터링 정책**: 로깅 가이드라인 및 관측 정책
- **보안 정책**: 사내망 접근 제어 및 인증 규격
- **네이버 세션 자동화 가이드**: 네이버 세션 자동 갱신 및 처리 구조

## 🔌 API 레퍼런스
상단 메뉴의 **API 명세서** 또는 사이드바의 **API 레퍼런스**를 통해 백엔드 서버의 OpenAPI 3.0 스펙을 기반으로 자동 변환된 명세서를 탐색할 수 있습니다. 
직접 요청 값을 넣어 API를 찔러볼 수 있는 **Try it out** 기능이 내장되어 있습니다.
